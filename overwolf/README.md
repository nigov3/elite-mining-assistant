# Overwolf overlay — prototype v0.1

Первый прототип для локального тестирования. Внутри окна открывается опубликованная тёмная веб-версия Mining Assistant (требуется интернет).

## Запуск

1. Установить Overwolf и включить оверлей для Elite Dangerous.
2. Склонировать репозиторий или скачать его ZIP и распаковать.
3. В настройках разработчика Overwolf выбрать **Load unpacked extension** и указать папку `overwolf` (в ней лежит `manifest.json`).
4. Запустить Elite Dangerous и нажать **Ctrl+Shift+M**. Если сочетание конфликтует с другим приложением, изменить его в настройках Overwolf.

## Ограничения

- Прототип не тестировался в клиенте Overwolf и самой игре.
- В манифесте `game_targeting: all`, поскольку ID Elite Dangerous ещё не подтверждён по официальному списку; приложение не использует игровые события.
- Отображение удалённой страницы в iframe зависит от политики встраивания GitHub Pages и Overwolf. Если iframe заблокирован, потребуется упаковать локальные ресурсы сайта в папку приложения.
- Вызовы оконного API и hotkey нужно проверить на реальном клиенте.
- Это исходники для загрузки в режиме разработчика, не опубликованное приложение Overwolf Store.
