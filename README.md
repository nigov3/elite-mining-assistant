# Elite Dangerous Mining Assistant

Веб-справочник по добыче ресурсов в Elite Dangerous.

## Версии
- [Светлая](./light/)
- [Тёмная](./dark/)

35 ресурсов, поиск на русском и английском, фильтр по типу колец и категории, сортировка по цене, огневые группы.

Цены справочные из пользовательской таблицы, не текущие рыночные котировки.

## Гайды E:D Black Box

В [каталоге](./dark/#guides) у каждого корабля одна раскрываемая карточка со ссылками на доступные роли. Поиск и фильтр специализации работают по всем досье; основные руководства и рейтинги кораблей остаются в отдельном списке. В открытом досье ссылка «Роли: …» возвращает к карточке этого корабля.

В [Базе знаний](./dark/#wiki) сначала показываются совпадения из гайдов Companion, затем страницы русскоязычной вики. После обновления гайдов индекс заголовков можно пересобрать командой `python scripts/build_guide_search.py`.

Проверки каталога, поиска и переходов: `node tests/smoke.mjs`.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
