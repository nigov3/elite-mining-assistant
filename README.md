# Elite Dangerous Mining Assistant

Веб-справочник по добыче ресурсов в Elite Dangerous.

## Версии
- [Светлая](./light/)
- [Тёмная](./dark/)

35 ресурсов, поиск на русском и английском, фильтр по типу колец и категории, сортировка по цене, огневые группы.

Цены справочные из пользовательской таблицы, не текущие рыночные котировки.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
